The file supplies low-intensity image-based lighting. The visible sky is a
separate original procedural sky mesh, so portal stencil clipping remains in
effect. Local hemisphere and directional lights remain if the HDR fails to
load. This asset is served from the project; runtime does not call Poly Haven.

existing credit is Poly Haven's `qwantani_sunset_puresky` in `ASSETS.md`.
